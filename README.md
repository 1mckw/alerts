### AR/AD 警報規則（1D / 1H · 同根數門檻）

| 類型 | 條件 |
|------|------|
| **觸碰** | 信號後超過 **10** 根才觸碰主引線 · 觸碰落在**最近 2** 根 |
| **接近未觸** | 信號在最近 **200** 根內 · 年齡 **≥ 60** · 引線仍有效 · 誤差 **0～1%** |

## AR/AD 規則

| | AR | AD |
|---|----|----|
| 觸發 | 急跌後反轉陽線 | 急漲後反轉陰線 |
| 射線 | 信號 K 上下引線各向右延伸，碰到即停 |
| 主引線 | AR→上引線、AD→下引線 |

**趨勢線：** 至少 3 觸點；上升支撐 + 下降阻力各 1 條（須 `valid_to_current`）；觸碰警報為最新 **5** 根內引線到線（誤差 **0%**）；觸碰警報線以細黃線標示；急漲/跌貫穿 grace 2 根 K。
